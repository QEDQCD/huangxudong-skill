# 设计：用 tudouhuang-2024 论坛语料扩充黄旭东 Skill

- 日期：2026-08-04
- 状态：待实现
- 相关文件：`SKILL.md`、`README.md`、`references/research/07-tudouhuang-2024-语料提炼.md`（新建）

## 背景

现有 `SKILL.md`（410 行）是基于 **~7 个精选 scboy 帖子 + 少量媒体报道** 构建的人物视角包，研究文件 `references/research/01-06` 也是从这批小语料提炼。`诚实边界` 标注调研时间为 2026-04-12，并坦承「很多模型主要来自论坛发帖与近年事件」。

新增语料 `references/research/tudouhuang-2024/` 是黄旭东（scboy.cc uid 89053 / 土豆黄）的 **267 页完整发帖史**，约 2664 条回复+主题，体量约为原素材的 100 倍，同时有 `.md`（人读表格）与 `.jsonl`（结构化）两份。样本（pages-001-010）已显示出现有 skill 未充分覆盖的方向：远不止 5 种的嘴硬模式、具体的业务操盘算账逻辑、可校验现有模型的密集一手证据。

## 目标

把新语料里的有效部分提炼出来，抽象成 skill 内容，补充进现有 `SKILL.md`，让角色拟合更准、操盘顾问能力更强、证据基础更扎实。不重写、不推翻现有结论，以补充校验为主。

## 已定决策

| 维度 | 决策 |
|------|------|
| 挖掘深度 | 主题式深挖（非全量精读，非纯缺口补齐） |
| 挖掘主题 | ① 嘴硬与对抗话术扩展 ② 业务操盘方法论 ③ 案例库 + 模型校验（不挖「游戏分析风格」） |
| 新旧关系 | 补充为主：保留结构与大部分结论，只修正被证伪处，补新模板/新案例 |

## 设计

### 1. 提炼方法（怎么挖 267 页）

每个主题走四步：**关键词 grep 定位候选 → 读上下文 → 聚类成模式 → 带引用归档**。`.md` 文件人读友好，作主战场；`.jsonl` 留作结构化备份/交叉核对。

- **嘴硬扩展**：grep 对抗性词（`造谣`/`脑补`/`闭嘴`/`封号`/`你tm`/`遭不住`/`搞毛`/`打住`/`不玩了` 等），收集命中场景，聚类成 5 套之外的新模板。
- **业务操盘**：grep（`赞助`/`成本`/`制作`/`赛制`/`场地`/`办赛`/`杯`/`联赛`/`排期` 等），抽取他办赛决策里的算账逻辑与资源获取方式。
- **案例库 + 校验**：对现有 5 心智模型 + 10 决策启发式，逐条在新语料里找 2-3 个带链接佐证；凡被证伪的，标注「证伪」并提修订。

采样范围声明：主题式采样，不是逐条全量精读；07 文件诚实记录覆盖范围。

### 2. `SKILL.md` 内联改动（载重内容）

**a) 嘴硬部分扩展（5 套 → ~10 套）**

新增候选模板（待语料验证后确认，每个至少 2 个独立帖佐证才立）：

| 候选模板 | 触发场景 | 样本信号 |
|----------|----------|----------|
| 反造谣 / 反脑补 | 被人脑补动机、结果推原因、造谣带节奏 | 「造谣我真受不了」「结果推原因然后脑补」 |
| 封号 / 闭嘴威慑 | 被 trolling、挑衅到点 | 「老子真想封你号」「你tm能闭嘴吗」 |
| 嫌烦 / 打住 | 话题发散到无意义争论 | 「说着说着又要拐到…不要再发散讨论了」「真尼玛遭不住」 |
| 资历压制 | 年轻人抱怨、站着说话不腰疼 | 「我们那时候坐绿皮火车…」 |
| 摆烂式硬气 | 输了/烦了，表演性摆烂但嘴不软 | 「不想玩了，5月1号开始呱」「我站着死也不会投降」 |

每套沿用现有「触发场景 + 默认回应骨架」格式，配 1-2 短例。

**b) 新增「业务操盘」内容**

- 新增 1 个心智模型：候选 **模型6「资源要自己去要，账要自己算清」**——办赛不是等资源，是主动去拉赞助、谈场地、拆成本；同时账要自己算清，内部结算价 ≠ 市场价。
- 新增 2-3 条决策启发式：
  - 办赛成本要自己拆清（案例：10w 办帕鲁杯 = 6w 奖金 + 5w 制作 + 自贴 1w，且 5w 是公司内部结算价，非市场价）
  - 赛制要算时间账（案例：bo1/bo3 排到半夜的时间测算，流程不顺要承认）
  - 排期互斥，项目不能同时开（案例：老头杯与帕鲁杯不能同时开，结束一个再看下一个）

各配短案例（沿用现有启发式的「应用场景 + 案例」格式）。

**c) 模型校验微调**

5 心智模型 / 10 决策启发式结论保留。在证据更强处补一句佐证或微调用词；被证伪处修订。校验结论（证实/证伪/部分修正）记录到 07 文件，`SKILL.md` 里只体现最终措辞。

**d) 路由表更新**

`Step 1: 先做场景路由` 的路由表补上新嘴硬场景的行（用户场景 → 优先模式 → 第一反应）。

### 3. 新文件 `references/research/07-tudouhuang-2024-语料提炼.md`

沿用 `01-06` 体例。结构：

1. **说明**：本文件基于 tudouhuang-2024 267 页语料的主题式提炼，非全量精读。
2. **主要来源**：tudouhuang-2024 索引（uid 89053，1-267 页，~2664 条），列出 `.md`/`.jsonl` 目录。
3. **按主题归档的案例库**：分三主题，每条 = 场景 + 原话引用 + scboy 链接（`#post_` 锚点）+ 支撑哪个模型/模板。
4. **提炼方法与审计**：grep 关键词清单、采样范围、每个新模板的佐证帖数。
5. **模型校验结论**：5 模型 + 10 启发式逐条标注「新语料证实 / 证伪 / 部分修正」+ 证据链接；证伪处给修订建议。

`SKILL.md` 在嘴硬部分、业务操盘、附录三处用「详见 `references/research/07-...`」指向它。

### 4. 保真与质量护栏

- 每个新模板 / 新案例必须带 scboy 原帖链接（`#post_` 锚点），可回溯。
- 校验类结论显式标注「证实 / 证伪 / 部分修正」，不悄悄改。
- 提炼审计写进 07 文件，诚实声明采样范围是主题式而非全量精读。
- 防 cherry-pick：每个新模板至少 2 个独立帖佐证才立，否则不立或降级为「待验证」。

### 5. 元信息更新

- `诚实边界`：调研时间 `2026-04-12` → `2026-08-04`；补一句「语料覆盖从 ~7 帖扩展到 tudouhuang-2024 的 267 页完整发帖史（~2664 条）」。
- `附录：调研来源`：在「一手来源」下加 tudouhuang-2024 索引说明。
- `README.md`：结构树补 `07-tudouhuang-2024-语料提炼.md`；`蒸馏过程` 补一步「2024 论坛语料提炼（嘴硬扩展 / 业务操盘 / 模型校验）」。

### 6. 验证

- 跑 `python3 scripts/quality_check.py SKILL.md`，确认结构完整、无格式破损。
- 人工 spot-check：抽 3-5 个新案例，核对引用链接与原帖内容一致。
- 角色冒烟测试：用几个命中新嘴硬模板的场景问 skill，看路由是否命中并生效。

## 不在范围内

- 不挖「游戏分析风格」主题（skill 是思维/操盘顾问，不是游戏教练）。
- 不重写现有 5 心智模型 / 10 启发式的结构，只微调和补证据。
- 不做全量 267 页逐条精读。
- 不改 `scripts/`、`sources/`、`LICENSE` 等无关文件。

## 成功标准

1. `SKILL.md` 嘴硬模板从 5 套扩到 ~10 套，每套有触发场景 + 回应骨架 + 短例。
2. `SKILL.md` 新增 1 个业务操盘心智模型 + 2-3 条启发式，配真实案例。
3. 现有 5 模型 / 10 启发式经新语料校验，结论或佐证更新；证伪处修订。
4. `07-tudouhuang-2024-语料提炼.md` 落地，含三主题案例库 + 校验审计，每条带链接。
5. `诚实边界` / `附录` / `README` 同步更新。
6. `quality_check.py` 通过；抽检链接一致；冒烟测试路由生效。
